# Landing page Dra. Brenda Loren

Projeto estático em HTML, CSS e JavaScript. Use o checkout existente;
não crie worktrees salvo quando a usuária pedir.

Para alterações de frontend, leia as skills locais:
- `skills/frontend-design/SKILL.md` — direção visual e implementação.
- `skills/web-design-guidelines/SKILL.md` — revisão de UX e acessibilidade.

As instruções da usuária e a identidade já aprovada prevalecem sobre
preferências estéticas das skills. Preserve a copy e as seções existentes
quando não houver pedido para alterá-las. As fontes e fotos fornecidas
precisam ser verificadas; não trate uma declaração CSS como prova de carga.

Servidor local: `python3 -m http.server 8765 --bind 127.0.0.1`.
Confira a composição no navegador em 320, 390, 768, 1024 e 1440 px,
incluindo menu, âncoras, botões e conteúdo externo. Diferencie a prévia real
do Instagram de um link alternativo mostrado por bloqueio de rede.

O ZIP de hospedagem deve conter `index.html` na raiz, `css/`, `js/`,
`assets/` e `LEIA-ME.txt`. Exclua `.git/`, `skills/`, `entrega/`, testes,
relatórios e estas instruções do pacote de hospedagem.
