# Skills locais para desenvolvimento web, UX e design

Duas skills foram baixadas dos repositórios oficiais e guardadas neste projeto. Não foram executados scripts de terceiros, instaladas dependências ou alterada a configuração global do agente.

- [frontend-design](frontend-design/SKILL.md): direção visual, tipografia, composição e revisão por capturas. Fonte: [anthropics/skills](https://github.com/anthropics/skills/tree/dbd4588f9e1033efb41dad4bef2f7947c8993d44/skills/frontend-design), commit `dbd4588f9e1033efb41dad4bef2f7947c8993d44`. Licença Apache 2.0 preservada em `frontend-design/LICENSE.txt`.
- [web-design-guidelines](web-design-guidelines/SKILL.md): revisão de UX, acessibilidade e implementação de interfaces web. Fonte: [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills/tree/063bee94c3f4df8453406c830b0a7df0f2860278/skills/web-design-guidelines), commit `063bee94c3f4df8453406c830b0a7df0f2860278`. O README de origem declara MIT; a declaração e o endereço exato estão em `web-design-guidelines/SOURCE-LICENSE.md`.

A segunda skill pede uma consulta atualizada às diretrizes a cada revisão. Há uma [cópia de referência](web-design-guidelines/references/web-interface-guidelines.md), obtida de [vercel-labs/web-interface-guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/434b7f91364665f2f733b310ec54809bf8f37937/command.md), commit `434b7f91364665f2f733b310ec54809bf8f37937`, com a licença MIT original em `web-design-guidelines/references/LICENSE`. Quando houver rede, atualizar a consulta conforme o SKILL.md; a cópia local torna a revisão desta entrega reproduzível.

## Como reutilizar

Peça ao agente para ler `skills/frontend-design/SKILL.md` e `skills/web-design-guidelines/SKILL.md` antes da tarefa. Estes arquivos são instruções locais, sem registro automático como ferramentas ou skills globais nesta interface.

As instruções do usuário e do projeto têm prioridade. Nesta landing page, preservar os textos, a identidade visual, os arquivos enviados e a estrutura existente; aplicar somente as correções autorizadas. As sugestões de novas direções visuais das skills não autorizam reconstruir a página ou substituir fotos reais.

As skills ficam no repositório para desenvolvimento e não fazem parte do ZIP de publicação na hospedagem. `sources.json` registra a origem e os hashes SHA-256 dos arquivos copiados sem modificação.
